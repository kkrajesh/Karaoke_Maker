# VoxPro: Karaoke Practice Dashboard

VoxPro (the `practice_app`) is the frontend Flutter desktop application for the Karaoke Maker ecosystem. It acts as the "Active Session" practice environment, automatically interfacing with the output generated by the Python core engine (stems, pitch profiles, and lyrics) to provide a rich, interactive singing experience.

> [!NOTE]
> As of **Phase 5**, the core UI, audio playback, pitch tracking, and lyrics parsing have been modularized and moved into the shared `vox_player_core` package. The `practice_app` now acts as a thin client shell that mounts the `VoxPlayerDashboard` and `UnifiedSearchUI`.

## 🚀 Features

- **Automated Library Scanning**: Uses `file_picker` and `MMDB` (MediaMonkey) via `vox_player_core` to instantly scan your `ONEDRIVE_HOT_ZONE`. (Transitioning from `es.exe` in Phase 9).
- **Automated Android Configuration**: Automatically requests `MANAGE_EXTERNAL_STORAGE` permissions on startup for seamless plug-and-play cross-platform use, and dynamically validates path mappings to prevent silent failures.
- **Smart Component Cards**: Displays interactive badges on songs indicating the availability of Instrumental tracks, Vocal tracks, Pitch Profiles, and Lyrics.
- **Global Quick Search & Filtering**: Features an instantly filtering search bar via `UnifiedSearchUI` with tri-state filters (Vocals, Instrumental, Pitch Data, Video).
- **Active Practice Session**: A dedicated UI shell powered by `VoxPlayerDashboard` that loads the `instrumental.wav` and provides scrubbable, fully functional media controls using `media_kit`.
- **Synchronized Vocals Guide**: Integrates flawlessly synced stem multiplexing for the `vocals.wav` file, allowing singers to instantly toggle the vocal reference track on and off mid-performance.
- **Live Pitch Visualizer**: A `CustomPainter` canvas that visually maps out the song's fundamental frequencies from the Python-generated `pitch_profile.json`. 
- **Live Mic Pitch Tracking**: Captures live microphone input via `record` and analyzes it at 43fps using the Yin algorithm in `pitch_detector_dart` to trace the user's live vocal performance against the reference guide.
- **Smart Section Highlighting**: Uses the `vocal_map.json` generated by the Python RMS analyzer to automatically shade the background of the pitch canvas.
- **Synced Lyrics & Meaning Display**: Automatically parses time-coded `.lrc` files natively inside `vox_player_core`'s Dual-Pane lyrics view.

## 🛠️ Tech Stack

- **Framework**: Flutter (Windows Desktop)
- **State Management**: `provider`
- **Audio Playback**: `media_kit` (Dual synchronized players, replacing old `audioplayers` implementation)
- **File System**: `file_picker`, `dart:io`
- **Analysis**: `pitch_detector_dart`, `record`

## ⚙️ Setup & Installation

1. **Prerequisites**
   - Ensure you have the Flutter SDK installed and configured for Windows desktop development (requires Visual Studio C++ workload).
   
2. **Install Dependencies**
   Navigate to the `practice_app` directory and run:
   ```bash
   flutter pub get
   ```

3. **C++ Compilation**
   The `media_kit` native C++ library handles audio and video playback, and `record` handles microphone input. Compilation on Windows requires CMake and Ninja (handled automatically by Flutter).

## ⚠️ Known Issues & Bugs

- **Windows Threading Crash**: When Hot Restarting (pressing `R`) while the live Microphone is active, the app may crash due to `record_windows` C++ memory teardown. Toggle the microphone off in the UI before initiating a hot restart.

## 🏃 Execution Instructions

To launch the practice dashboard on Windows:

```bash
cd practice_app
flutter run -d windows
```

### 📱 Testing on Android via Wireless Debugging (Android 11+)
If you want to test on an Android tablet wirelessly without a USB cable:
1. Ensure your tablet and PC are on the same Wi-Fi network.
2. Enable **Wireless debugging** in the tablet's Developer Options.
3. Tap **Wireless debugging** -> **Pair device with pairing code**. Note the IP, Port, and 6-digit code.
4. On your PC, open a terminal and run:
   ```bash
   adb pair <IP>:<PORT>
   ```
   *(Enter the 6-digit code when prompted).*
5. Back on the main Wireless debugging screen, note the *new* port under "IP address & Port".
6. Connect via ADB:
   ```bash
   adb connect <IP>:<NEW_PORT>
   ```
7. Verify the device is connected:
   ```bash
   flutter devices
   ```
8. Run the app:
   ```bash
   flutter run
   ```

### Usage Workflow
1. Launch the app.
2. The UI will mount the `VoxPlayerDashboard`. 
3. Open the **Unified Search** overlay.
4. Click on any parsed Song Card.
5. Hit **Play**, toggle the **Vocals Guide**, turn on the **Microphone**, and sing along with the **Pitch Canvas**!
