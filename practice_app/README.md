# VoxPro: Karaoke Practice Dashboard

VoxPro (the `practice_app`) is the frontend Flutter desktop application for the Karaoke Maker ecosystem. It acts as the "Active Session" practice environment, automatically interfacing with the output generated by the Python core engine (stems, pitch profiles, and lyrics) to provide a rich, interactive singing experience.

## 🚀 Features

- **Automated Library Scanning**: Uses `file_picker` to point to your `ONEDRIVE_HOT_ZONE`. The dashboard automatically scans all subdirectories and parses the generated assets into a sleek, dark-themed UI.
- **Smart Component Cards**: Displays interactive badges on songs indicating the availability of Instrumental tracks, Vocal tracks, Pitch Profiles, and Lyrics. Users can click any badge to idempotently reprocess just that specific component or inject manual files.
- **Global Quick Search**: Features an instantly filtering search bar in the library view and a globally accessible search overlay in the Active Session to seamlessly switch songs mid-practice.
- **Active Practice Session**: A dedicated UI shell that loads the `instrumental.wav` and provides scrubbable, fully functional media controls.
- **Synchronized Vocals Guide**: Integrates a secondary, perfectly-synced audio player for the `vocals.wav` file, allowing singers to instantly toggle the vocal reference track on and off mid-performance.
- **Live Pitch Visualizer**: A `CustomPainter` canvas that visually maps out the song's fundamental frequencies ($F_0$) from the Python-generated `pitch_profile.json`. The target pitch notes scroll beautifully in sync with the audio playhead.
- **Smart Section Highlighting**: Uses the `vocal_map.json` generated by the Python RMS analyzer to automatically shade the background of the pitch canvas. It provides an immediate visual map of vocal sections (Neon Pink) versus instrumental breaks (Neon Teal) so singers know exactly when to rest.
- **Synced Lyrics & Meaning Display**: Automatically parses time-coded `.lrc` files (Native or LLM-transliterated English) and renders the active lyric line in large, readable text overlaid on the pitch canvas. Also supports rendering the LLM-generated Poetic Meaning of the song.

## 🛠️ Tech Stack

- **Framework**: Flutter (Windows Desktop)
- **State Management**: `provider`
- **Audio Playback**: `audioplayers` (Dual synchronized players)
- **File System**: `file_picker`, `dart:io`
- **UI/UX**: Custom `VoxProTheme` (Glassmorphism, Deep Dark Palette, Neon Accents)

## ⚙️ Setup & Installation

1. **Prerequisites**
   - Ensure you have the Flutter SDK installed and configured for Windows desktop development (requires Visual Studio C++ workload).
   
2. **Install Dependencies**
   Navigate to the `practice_app` directory and run:
   ```bash
   flutter pub get
   ```

3. **Windows Compiler Fix (Important)**
   The `audioplayers` package on Windows currently throws C++ coroutine deprecation errors on newer MSVC compilers. This project has been pre-configured to bypass this.
   *(In `windows/CMakeLists.txt`, the `add_compile_definitions(_SILENCE_EXPERIMENTAL_COROUTINE_DEPRECATION_WARNINGS)` flag is enabled to ensure smooth compilation).*

## 🏃 Execution Instructions

To launch the practice dashboard on Windows:

```bash
cd practice_app
flutter run -d windows
```

### Usage Workflow
1. Launch the app.
2. Click the **"Library"** tab.
3. Use the file picker to select your `ONEDRIVE_HOT_ZONE` folder (where the Python engine outputs the song folders).
4. Click on any parsed Song Card to route to the **"Active Session"**.
5. Hit **Play**, toggle the **Vocals Guide**, sing along with the **Lyrics**, and follow the **Pitch Canvas**!
